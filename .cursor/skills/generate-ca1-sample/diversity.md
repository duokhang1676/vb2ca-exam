# Diversity 0–10

Applies to both parts. Content must stay inside [spec-ca1.md](spec-ca1.md).

| Score | Phần 1 | Phần 2 |
|---|---|---|
| **0** | Same core theme and layout as the closest bank/minh họa essay; new numbers, names, wording | Same problem types and topic order; change numbers only |
| **1–2** | Same theme group; rewrite the passage | Same templates; light variants |
| **3–4** | Adjacent core theme | Keep topic mix; new contexts |
| **5** (default) | Prefer a core theme underused in the bank | Mix familiar and less common templates; shuffle order of 1–39 |
| **6–7** | New angle; different passage situation | Low overlap with bank; new cluster passages |
| **8–9** | Unused core theme; less similar to bank | Max variety of types in syllabus; slightly harder |
| **10** | New passage and task, still one official core theme + 500-word nghị luận | Max variety; never leave CA1 Toán cao cấp |

Even at 0, change numbers and wording enough to pass fingerprint / near-dup (`NEAR_DUP_JACCARD = 0.55`). Exact clones are skipped on import.
